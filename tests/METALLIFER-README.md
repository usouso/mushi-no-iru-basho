# 0.17.0：メタリフェル1種の接続

## 根拠と表現
雄のメタリフェルホソアカクワガタ（Cyclommatus metallifer）を、既存の東南アジア林の観察区画へ1匹追加します。インドネシア原産、長い雄の大顎については[北海道大学の種紹介](https://www2.sci.hokudai.ac.jp/dept/bio/organism/1008)を参照。幅広い頭・細い前胸・金褐色・長い左右の顎は同大学[2014年研究広報・図1](https://www.hokudai.ac.jp/news/140206_pr_ees.pdf)を目視し、独自の低ポリゴン形状を制作しました。資料画像のトレース・テクスチャ化・同梱はしません。

顎途中の大きな内歯と長い顎については[Goyensらの一次研究](https://doi.org/10.1098/rsif.2015.0768)も参照。研究の力の数値や個体差をゲームの強さへ換算していません。模型は特定亜種の同定精度を保証しません。

低い太枝は見つけて観察するための配置で、自然の代表的な高度/樹種/摂食場所を意味しません。野外食性と活動時刻は未確定です。既存の果実餌へこの種を自動的に追加していません。表示上は胴16cm・顎込み36.7cmで、実寸の記録ではありません。

## 一巡と互換性
- 発見・網で捕獲 → 図鑑記録/観察 → 任意保有または放虫。
- 仲間として連れた原個体は再捕獲できない。区画往来/再開始/読込で複製しない。
- 0.18では見守り型COM相撲。顎を掛け直した後の押し合いが少し得意というゲーム上の調整で、現実の闘争能力とは区別。
- 勝敗・中止で失わない。明示した返却で元の枝へ戻す。図鑑は残る。
- `mushi-journal-v2` と `mushi-companions-v1` を継続。旧20種記録と旧3種保有はそのまま読み、旧版が認識できない新種を上書き削除しない。実ユーザーストレージへ直接触る検査はしない。

## 実行と限界
リポジトリルートで `node --test tests/*.test.mjs`（Node 24.22.1）。テスト用ファイルは本番のimportグラフから読み込みません。

CPU幾何・純粋ルール・明示的なDOM/storage/renderer代用品を使う検査です。実WebGL・実音・実機FPS・本物の保存・発見しやすさ・対戦の楽しさを合格扱いしません。短い枝上歩行は小さい表示変形rigで、骨長・関節の厳密再現ではありません。新しい音、通信、依存は追加していません。
