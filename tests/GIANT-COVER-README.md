# オオクワガタの後退反応 — 0.29.0

変更は1種の警戒予兆 **0.35→0.22秒**、後退速度 **0.12→0.30m/s** のみ（表示倍率に応じた既存補正あり）。既存の実庇・支持枝・退避距離・歩行骨長・退く方向・捕獲2.6m・個体差・保存・相撲は変えません。

## 狙い
空振りしてもほとんど動かない印象を減らし、素早く隙間へ退く姿を手掛かりに、そっと寄る・低い開口や側面から狙う・離れて戻るのを待つ余地を作ります。最初から正確に狙った網は残します。不可視化、瞬間移動、無敵時間、目線だけを無視する特別な捕獲拒否は追加しません。

静かな低い目線では開口の下が見え、同じ射程と実際の遮蔽判定で捕れます。接近方向によって庇とは逆へ退く場合もあります。全角度から必ず隠れる/必ず逃げ切る変更ではありません。

## 最小試遊
夜の林縁、太い木の西側の低い樹皮際で、次の違いが見えるかだけ確認します。
1. 普通/ダッシュ接近や近い空振りで、顎の予兆から素早い後退へつながるか。
2. 右クリックの静歩や横からの再接近、少し離れて待つ方法に意味を感じるか。
3. 脚が忙しすぎないか、滑る/瞬間移動/庇を突き抜けるような不自然さがないか。

実画面・実音・実ブラウザ保存・捕獲の楽しさは未確認です。人の試遊の代わりに検査数を品質保証とはしません。
