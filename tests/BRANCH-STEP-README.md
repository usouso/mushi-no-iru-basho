# 0.36.0 — 歩き始めの警戒待ちを短くする

## 直す問題
枝を歩き始めた直後に近づいたり網を外したりすると、虫が半歩を終えるまで極端に待つ場合がありました。60Hzの再現では、歩速がまだ約0.00111m/秒のとき、警戒姿勢に入るまで18.15秒かかります。

対象はカブトムシ、ノコギリクワガタ、オオクワガタ、ゾウカブト、ゴライアス、ゴホンヅノ、ミヤマの既存枝上動作。**警戒に入る前の同じ半歩だけ最大0.6秒で終える**ようにします。必要な場合は短く加速して接地位置まで進む近似です。急な瞬間移動や、足を置かずに警戒へ切り替える処理ではありません。

接近条件、静歩の有効性、捕獲射程、通常の休止・歩速、警戒姿勢、後退距離・速度、セーブ、寸法、相撲は変えません。アトラス、メタリフェル、テナガコガネ、および枝の制限を使わない旧動作は対象外です。カブトムシは既存の警戒から飛翔準備への接続を維持します。

## 再現検査

```sh
node --test tests/branch-step-finish.test.mjs tests/branch-step-main-loop.test.mjs
```

限定検査は、同じ半歩の終点と開始・終了速度、正逆方向、大きさ補正、途中の捕獲・返却、重複刺激でやり直さないことを確認します。実模型の245姿勢・1470足レイと固定脚長も検査。DOM／レンダラー／保存の代用を使う実main検査は、実ブラウザ操作やWebGLの代わりではありません。以前の全テストを反復した数字ではありません。

## あとで試す点

- 歩き始めた虫へ普通に近づいた時や網を外した時、立ち止まって反応するまで不自然に待たないか。
- 静かに寄って狙いを合わせれば捕れるか。虫が見えて届く警戒中も捕獲できます。
- 脚の運び、警戒、後退／カブトムシの飛翔準備が自然につながるか。

新しい虫・区画・音・勝敗ルール・セーブ形式はありません。実画面・実音・実ブラウザ保存・人間の自然さは未確認。元セーブの削除や破損試験は不要です。
