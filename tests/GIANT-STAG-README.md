# オオクワガタの追加と検査（0.23.0導入時の記録）

**以降の変更**：0.26.0から新しい散策では個体差と大きさ記録に対応しています。旧固定個体は未計測で保護されます。0.29.0では予兆と後退速度のみ調整。現在の試遊は `GIANT-COVER-README.md` と `../PLAYTEST-JA.md` を参照してください。以下の種数・固定個体の説明は導入当時の記録です。

既存の夜の林縁に、固定のオオクワガタ雄1匹を追加。23種・5区画、仲間と自動虫相撲は6種です。新しい区画・相撲ルール・音素材はありません。

## 遊ぶ
夜の樹液の木の左側、低い樹皮際を見てください。急いで近づくと顎を構え、枝を歩いて隙間へ退きます。庇で見えない正面から網は届きません。横から静かに近づくか、少し離れて戻るのを待てます。捕獲後に回して観察・図鑑記録・放虫、または「この虫でバトル」で仲間にして見守れます。

今回は固定の未計測個体です。実寸を測った表示や大きさ記録を捏造しません。模型は胴と頭約18.5cm／大顎込み約29cmという見分けるための表示補正です。以前の虫の大きさは変更しません。

## 再実行
Node 24.22.1。追加インストール不要。リポジトリのルートで:

```sh
node --test tests/giant-stag-*.test.mjs
node --test tests/published-graph.test.mjs
```

- model: 6脚の固定骨長・接地、太い大顎と大きな内歯、4枚の翅（後翅は収納）、実表面の接点、独立破棄、旧25模型/歩行モジュールの意味内容不変。
- study/simulation: 正常／静かな接近、予兆→連続退避→戻り、実支持枝と庇の遮蔽、側面からの再接近、捕獲・返却の位置連続性。
- loop: 実mainを代用DOM/音声/保存と実Three形状で動かし、網→観察→図鑑→保持→COM→取消・帰還→区画移動→保存再読→返却→再捕獲。
- data: 図鑑v2/仲間v2の許可種だけ追加。旧元データを消さず、失敗時は未保存を示します。旧5散策枠・個体ID・測定形式は不変、新個体は `night/insect-6`。
- battle: 新種を含む11対戦・22場外クリップで顎の実頂点→胴の実三角形、支持脚、着地、白線外の胴・足と画角を検査。旧5種の規則出力hashを比較。大きさは勝敗に使用しません。

これらはCPU/代用環境の検査です。実WebGL、実音、実ブラウザの永続保存、パッド、夜の見つけやすさ、動きの自然さや面白さは別途試遊が必要です。模型は低ポリゴンの自作見本で、精密な生体運動・飛行・摂食は再現していません。

## 生態と形の参照
- [S-Net・姫路科学館の雄標本](https://science-net.kahaku.go.jp/search/detail?cls=collect11&pkey=2405779): 参照した学名表記 `Dorcus hopei binodulosus`。
- [Kim & Kim (2010), Review of the family Lucanidae in Korea](https://www.zin.ru/animalia/coleoptera/pdf/kim_kim_2010_review_lucanidae_korea.pdf): 幅広の頭・胸、発達した大顎と大きな内歯。資料中の雄27.0〜76.1mmは大顎先端から上翅末端の範囲で、全野生個体の最小最大ではありません。
- [岐阜県の紹介](https://www.pref.gifu.lg.jp/page/4843.html)、[大阪市立自然史博物館の記録](https://dom.ocm.osaka/database/omnh/2955): 広葉樹林、樹洞・樹皮下、夜の樹液利用を参考にしました。

写真・図版・他ゲームの形や名称を複製していません。低い枝の位置、退避距離、反応速度は観察と捕獲のためのゲーム調整値です。
