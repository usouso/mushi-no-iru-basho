# 個体差と新しい散策の小さな試作

既存21種のうち、ヘラクレス2匹・カブトムシ1匹・ノコギリクワガタ1匹・メタリフェル1匹が対象。個体数や種数を減らさず、同じ倒木/枝の3つの支持位置から出現位置と、歩き始める待ち時間を選びます。ほか17種の配置/大小は従来のままです。

## サイズの意味
同種の現行模型を100として100〜115の範囲。上側は少なめにした**ゲームの表示指標**で、実寸mm、自然の個体分布、戦闘能力の測定値ではありません。従来より小さくして見つけにくさを戻さず、野外・観察・保有した模型・対戦表示で同じ倍率を使います。観察の狭い画面では顎先の欠けを防ぐfit上限があります。身体全体の一様拡縮は簡略化で、小型雄と大型雄の角/顎の比率差までは再現しません。

捕獲成功時に「今回の大きさ」と種ごとの自己最大を記録。同じ個体の再捕獲では再抽選・自己最大演出の繰返しをしません。大きいから自動的に勝つ規則はありません。旧保有個体は「未計測」で、後から架空の測定値を足しません。

## 散策の更新
休止メニューの「新しい散策を始める」でのみ、保存に成功してから顔ぶれを更新します。観察・表紙往来・区画移動・再読込では再抽選しません。初期保存処理中は開始を待ち、書込み失敗/競合/未知データでは元の散策を保持。新散策の保存中に別画面へ移った場合は、新しい入口で休止したまま待ちます。

新しい `mushi-expedition-v1` にseed、個体manifest、現在の散策番号、計測済みIDと種ごとの最高記録を一緒に保存。旧図鑑の `mushi-journal-v2` は変更しません。仲間は `mushi-companions-v2` に一度だけ移行し、旧 `mushi-companions-v1` の原文を更新/削除しません。新key優先で、旧版で後から増えた保有を自動的に再移行して復活させません。未知・破損・競合・成否不明の書込みを上書きしません。Web Locks非対応等では未保存表示を出し、固定配置/ページ内での遊びを残します。

同種の虫を捕まえたときは、現在の仲間のサイズと返却の結果を表示し、2クリックで明示的に入替。先に元の仲間を削除する処理はせず、勝敗や画面移動で失いません。野外の除外は新しい個体IDを照合し、以前の散策の仲間が新しい個体まで消すことを防ぎます。

## 2種の捕獲に警戒を追加
アキアカネとアブラゼミだけ、ダッシュで近づくと網の射程2.6mに入る前に翅の予備動作から連続して飛び立ちます。近くの見える方向への空振りは最大1匹に作用。静歩行では射程へ近づけ、逃げた後も着地を見て再挑戦できます。射程を縮めたり飛行中を無敵にしたりはしません。対戦甲虫を含む他19種まで逃避が改善したとは扱いません。

アブラゼミが脅威から飛び立った後に同じ木/近隣の木へ移る傾向は [Takakura & Yamazaki (2007)](https://academic.oup.com/aesa/article/100/5/729/8407) を参照。トンボの接近反応の種差は [Bell et al. (2019)](https://www.worlddragonfly.org/article/13887890-2019-1668306) を参照。後者はアキアカネの実測ではなく、ここでの半径/秒数/翅の予兆はゲーム調整です。

## 検査と限界
`node --test tests/*.test.mjs`。個体store/旧保有移行/同時タブ/保存失敗、実mainの捕獲・交換・再読込・新散策、実Three.jsの支持と個体倍率、実シミュレーションの歩行・果実への移動・捕獲凍結、fast/quietの差と遮蔽越し空振りを検査します。DOM・WebAudio・storage/locks・WebGL rendererは代用品。実画面での見つけやすさ、聴感、自然さ、緊張感、本物の保存/性能は未確認です。実ユーザーデータを削除する検査は不要です。
