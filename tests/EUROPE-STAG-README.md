# 0.43.0 ヨーロッパミヤマクワガタの限定検査

## 一巡と境界
Lucanus cervus 雄の自作模型と、欧州広葉樹林縁を参考にした小区画です。入口から低い倒木へ近づき、捕獲・観察・図鑑・任意メモ・仲間・既存自動相撲・明示返却につながります。31種・8区画・相撲14種。新しい虫は固定の未計測個体で、元の8枠の散策記録、表示指数、最高記録を引き直しません。

黒い頭胸、栗色の上翅、赤褐色の鹿角状大顎を一次資料本文から独自に近似。模型の頭胴約19cm・顎込み軸長約32cmはゲーム表示寸法で、自然の体長ではありません。閉じた上翅の内部の後翅は未モデル化。新飛行・餌・時計・天候・戦闘規則はありません。

## 再実行
Node 24系でリポジトリのrootから。追加依存はありません。

```sh
node --test tests/europe-stag-*.test.mjs tests/published-graph.test.mjs
```

このコマンドは新規7ファイル31条件と配信グラフ1条件です。全旧テストの実行を意味しません。

**52個の限定public条件**です。既存全suiteの合格ではありません。変更された旧Atlas大matrix条件はregistry/source guardのprefixだけを独立に確認し、全49対matrixは再実行していません。これを53件目のfull passとは数えません。別に実旧042コードを使ったfresh/staleの記録4ケースで新種データを自動上書きしないことをMap上で確認しました。

実mainは本番moduleをDOM・WebGL・audio・Mapのテスト代替と一緒に動かしています。実ブラウザの描画や永続性を合格にするものではありません。模型・実カメラのCPU投影画像は確認しましたが、ライティングや動きの気持ちよさは未検証です。

## 実形状の有限確認
- 倒木上の36pose・216本の実足skin ray。最大足面差は約5.6e−17m、最小skin余裕は約0.30nm。これは数値一致であって実物の精密性ではありません。
- 連続通路のplayer collider余裕は最小約45cm。9lane点から通常・静歩の実LOS/捕獲可能距離を確認。
- 54相撲clips・378poseで欧州種の実顎triangle接触を要求。接点差約13nm、既存メタリフェルの3link tube skinも22,176vertexで別確認。連続衝突の完全証明ではありません。
- 実main観察3画面比×16方位×3傾きで846,144vertex。最大NDC絶対値はX約.706/Y約.676。数値的枠内と実画面の読みやすさは別です。

## 生態根拠
- [Natural History Museumの収蔵担当者による解説](https://www.nhm.ac.uk/discover/stag-beetles.html)：雄の鹿角状大顎、色、夕方の活動、液体食等。
- [JNCC保全資料](https://sac.jncc.gov.uk/species/S1083/)：広葉樹の地面に接する腐朽木と幼虫、暖かな夕方の成虫活動。
- [PTESの当該種調査](https://stagbeetles.ptes.org/about-stag-beetles/)：同定・形態の補助。
- [伊丹市昆虫館研究報告4号](https://www.itakon.com/wp/wp-content/uploads/2019/04/bull_icmi_no04.pdf)：和名と学名の対応。

画像素材の転載・トレースはありません。小区画の植物、倒木上の高さ、歩速、警告秒数、相撲の押す強さは独自のゲーム調整で、野生測定値や自然な群集の再現とは主張しません。

発見性と夕光、静かに接近する余地、脚と顎の動き、場外の見分けやすさ、実音、実ブラウザ保存、gamepadは未確認。旧タブは新種を理解できないため、元データを消さず同じ新版へそろえます。README・既存13音・ライセンス・外部通信は変更していません。
