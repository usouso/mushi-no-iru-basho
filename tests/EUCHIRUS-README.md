# テナガコガネ（暫定表示名）— Euchirus longimanus 雄

## この候補の範囲

既存の東南アジア林 `understory` に、雄1個体を末尾 `insect-7` として追加します。長い左右の前脚と、短い中後脚を見分ける虫です。実際の木の面へ載せ、発見・接近・捕獲・観察・図鑑・仲間・自動COM相撲・返却を接続しました。プログラムと実形状のCPU検査済みですが、**実WebGL・聴感・実ブラウザ保存・人間の遊び心地は未検証**です。

- 図鑑28種目、仲間・相撲の登録11種目。旧種のprofileや相撲ルールに変更はありません。
- 固定の未計測個体です。大きさ指数・自然の体長値を新しく抽選したり、保存済みの個体へ付け足したりしません。既存の散策7枠と g1/g2/g3 の生成は不変です。
- 仲間は同種1個体。返却・入替は既存の明示操作を使います。架空の別originを作って入替対象を増やしません。
- 役割表示は「長い前脚で押し合う」。**本種の野生の雄同士の闘争は確認できていません。前脚の押し合いはゲーム動作であり、野生闘争の再現ではありません。** 新しい操作ルール・強さ補正・サイズ加点はありません。

## 再現検査

```sh
node --test tests/euchirus-*.test.mjs tests/journal-capacity.test.mjs
```

テスト専用Map保存とWeb Lock代用を使います。旧27記事の日時・場所・任意500文字メモ、旧10仲間（g1/g2/g3と固定null）、旧キーraw、不正origin・未知種・未来形式のreadonly、容量不足・競合の保護を検査します。実ブラウザ保存の保証ではなく、実ユーザーの保存を消す／壊す試験は不要です。

模型4・支持3・動作4・登録6・実main4・相撲4の各条件を分けて検査します。実際のmesh/骨長/足場はCPUで計算しますが、レンダラー・入力DOM・保存には代用を使うため実機評価とは異なります。

- 支持は既存木の実三角面。地形や透明足場を増やしません。半歩を終えて4本で支えてから前脚を小さく上げ、前脚を戻して短く上へ進みます。
- 相撲は新種を含む21組・両勝敗42終端を有限姿勢で検査。二本の前脚の実接点で短く押し、足を置き直して後退・前進します。連続した物理力学計算ではありません。新種組の場外終端は3.20秒、旧10種同士の描画・規則は不変です。
- メタリフェルが相手の新種組だけ、固定脚長を保つため12mmの短い足運びを使います。足の動きが細かすぎないかは実画面未確認です。旧種同士の歩行は変えません。
- 大量のメモで保存済みなのに再読込で空に見える容量不整合も修正。500文字の上限は維持し、JSONの文字エスケープを含め、読取と書込の有限上限を揃えました。元データを削除しません。古いタブが大きな保存を表示できなくても上書きしないことを検査しています。
- あとで試す点は、長い前脚で他種と見分けられるか、接近時の反応が読めるか、相撲の接触と場外勝ちが分かるか。旧セーブを消す必要はありません。

## 根拠と限界

既存の一次資料調査を参照しています。新たな自然寸法・生態の数値を設定しません。

- [上海自然博物館：Euchirus longimanus の所蔵標本](https://www.snhm.org.cn/cpjc/info.htm?eid=523)：本種の長い前脚・前胸・上翅の見分けに使用。
- [華西昆虫博物館提供標本](https://artsandculture.google.com/asset/euchirus-longimanus-zhao-li/yQF1EQ2bMjx9Ug?hl=en)：学名と標本情報の照合。
- [国立環境研究所：Euchirus spp.](https://www.nies.go.jp/biodiversity/invasive/DB/detail/60370.html)：**属全体**の形態・生態資料。樹液や灯火の記述を、この種の食性・活動時刻の断言へ転用しません。

写真の転載・素材化・輪郭トレースはありません。観察しやすい木の面、支持脚の動き、押し合いはゲーム上の配置・近似であり、自然の好み・歩行速度・闘争行動を測定して再現したものではありません。
