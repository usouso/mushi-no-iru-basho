# ヘラクレスの網空振りへの反応

網を外しても無反応だったヘラクレスを、既存の倒木上の旋回・歩行へ接続します。足場、移動距離、歩速、大きさ、捕獲判定、音、相撲ルールは変更しません。

- 見えている近い個体だけが反応します。既に歩いている虫は網連打で再始動しません。
- 果実へ向かう/そばで休む個体は、既存の接地停止から元の場所へ帰ります。果実は消しません。
- 停止後の抑制中に新しく近づいた場合、その入口を一度だけ保留します。離れれば取り消し、同じ観察者へ周期的に逃げ続けません。
- 通常とダッシュの接近範囲は従来同じ1.5m、静歩は0.8mです。新しい威嚇ポーズ・警告タイマー・捕獲免疫はありません。端で動けなくても見えて届けば捕れます。

## 再現検査
```sh
node --test tests/hercules-response.test.mjs tests/hercules-response-main.test.mjs tests/log-fruit-simulation.test.mjs tests/published-graph.test.mjs
```
実Three.jsと実main、代用DOM/音/保存で検査します。検査コードは本番へ読込みません。

実mainで、失敗した網の実際の再使用待ち43frame中に約10.2cm移動し、その後の再照準で捕獲できる1例を確認しています。個体の初期向きや倍率で変化するため全状況の保証ではありません。捕獲→測定→仲間→COM取消→返却→再捕獲で、同じ個体を重複計測しないことも確認しています。

**実WebGL・実音・実保存・見える反応の自然さと捕獲の緊張感は未確認。** 新しい生態数値の主張や、必ず逃げ切るという保証ではありません。

あとで見る点は「外した網に反応が見えるか」「追いかけて照準を直すと納得して捕れるか」の2点です。
