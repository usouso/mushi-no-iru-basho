# 二匹の接触振付の限定検査

`node --test tests/battle-choreography*.test.mjs tests/atlas-choreography.test.mjs`
全体は `node --test tests/*.test.mjs`（Node 24.22.1、外部依存の追加なし）。検査ファイルは本番から読み込みません。

- 角型の胴下への差し込みと顎型の掛け合い。実際の武器メッシュの先端と相手の胴の三角形を検査し、別々の模型をただ平行移動するだけにしません。
- 旧4種の16組を大小/左右の96構成、アトラスを含む9組を大小/左右の34構成で確認。接触点・実際の脚先の皮膚・支持姿勢・連続性・長角の画面内収まりをCPUで計測します。サイズは見た目のみで能力に使いません。
- 時間0/中断/復帰、動きを減らす設定、終了後の模型復元、音イベントの一度だけの発火を確認。最終ラウンドの論理勝敗が先に決まっても、動作が終わるまで結果表示を待ちます。
- 振付自体は勝敗・保存を変更せず、野外/観察の形状とも分離しています。0.21では本人要望により終局ルールだけを場外勝利・時間切れ引分へ変更しました。新種の追加分は別の `ATLAS-README.md` に記載。

ここでの描画は代用品、形状確認は実Three.jsのCPU変換です。実WebGL、実音、実ブラウザの保存、迫力・自然さ・楽しさは未確認です。投影図は実ブラウザ画像ではありません。実機では接触と反応が一続きに見えるか、脚や角が不自然に伸びないか、短い衝撃音が接触時に聞こえるかを確認してください。
