J／Esc／右保持と見回し案内、5区画切替、各種の捕獲→観察→放虫、2箇所の果実、遮蔽、図鑑と任意メモ、同一配信tokenを確認します。追加した昆虫の純粋状態テストを含みます。カブトムシとノコギリクワガタは短い前進・後退、接地停止、捕獲中の凍結、同じ姿勢からの返却を扱います。クワガタの大顎の開閉途中も検査します。働き蜂は2つの花への訪問・離着花と4翅連動を扱い、空中捕獲・返却も確認します。アゲハは斜面への6脚支持姿勢と短飛行のquaternion、捕獲途中の位置/翅状態を扱います。タマムシは葉上の正逆歩行・接地停止と同姿勢返却を確認し、飛行は対象外です。野外の反応や自然さの評価ではありません。

保存は `mushi-journal-v2` 専用です。認識できるv1データは一方向移行し、旧キーを更新・削除しません。未知・破損データや他タブの編集を上書きしない、成功markerを同じ書込みに含める、Web Locks非対応／失敗時にmemory-onlyになることをMapで検査します。`tests/fixtures/journal-locks.mjs` は非同期exclusive callbackを再現する明示mockであり、実ブラウザの排他保証を検査したものではありません。

実Three.jsの座標・行列に対し、DOM、Canvas塗り、音、pointer lock、WebGL renderer、ゲームパッド、storage／Web Locksは代用品です。標的近くにカメラを設定するケースを含みます。**実画面・実音・実機FPS・実パッド・ブラウザ保存・自然さ・発見性の合格ではありません。**
