実Three.jsの座標・行列に対し、DOM、Canvas塗り、音、pointer lock、WebGL renderer、ゲームパッド、storage／Web Locksは代用品です。標的近くにカメラを設定するケースを含みます。**実画面・実音・実機FPS・実パッド・ブラウザ保存・自然さ・発見性の合格ではありません。**
