# ゾウカブトの追加と検査（0.25.0）

既存の中米熱帯林にゾウカブトの雄1匹を追加。24種・5区画、仲間と見守る虫相撲は7種です。新区画・餌・相撲ルール・音素材の追加はありません。

## 探して、捕まえて、見守る

熱帯林の入口から左へ。果実のある倒木のさらに西、木につながる低い斜めの枝で、幅広く丸い体と前へ伸びる角を探します。走って近づくと頭角を構えてから枝を歩いて退きます。足を止め、静かに接近すると捕まえられます。距離・速度は観察と捕獲のためのゲーム調整値で、測定された生態値ではありません。

捕獲後は回して観察・図鑑へ自動記録・放虫、または「この虫でバトル」で仲間にして自動虫相撲へ進めます。場外だけ勝ち、時間内に決まらなければ引き分け。勝敗で仲間を失いません。

固定の未計測個体 `tropical/insect-11` です。旧10個体の順序・ID、ランダム散策5枠、保存キーは変えません。頭と胴の模型寸法は約23cm、体軸方向の角込み約35cmという見分けるための表示補正です。現実の個体寸法や自己ベストを捏造せず、旧個体のサイズも変えません。

## 再実行

Node 24.22.1、追加インストール不要。リポジトリのルートで:

```sh
node --test tests/elephant-*.test.mjs
node --test tests/published-graph.test.mjs
```

- study/simulation: 木につながる傾斜枝、支持面と脚・腹部、通常/ダッシュ/静歩行、予兆→連続退避→戻り、見通しと網の空振り、捕獲/返却の位置連続性。旧果実訪問とアリ列を維持。
- loop/data: 実mainを代用DOM・音声・保存と実Three形状で実行。網→観察→図鑑→仲間→COM→取消/帰還→区画移動→保存再読→返却/再捕獲、未保存時の保護を確認。旧データを消しません。
- battle: 新種を含む13対戦・26場外クリップの実角頂点と胴三角形の接触、頭/首の接続、支持脚、着地、白線外の胴/足、画角を検査。旧6種の規則出力を固定hashと照合。大きさを勝敗へ加点しません。
