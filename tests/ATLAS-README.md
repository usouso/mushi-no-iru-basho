# アトラス雄1種の探索・捕獲・見守り相撲

## この候補の範囲
既存21種/5区画を残し、「東南アジア林」の入口右側にアトラスオオカブト（Chalcosoma atlas）の雄1匹を追加。既存コノハムシ3匹とメタリフェルの順番・ID・支持物は変更せず、新個体は `insect-5` です。三本角の自作模型、接地した太枝、捕獲・全周観察・図鑑・保持・既存の自動虫相撲・任意返却までを接続します。

初回のアトラスは固定個体・未計測です。0.19の4種5個体の乱数manifest/最大記録を変更せず、旧散策を再抽選しません。仲間v2の許可種だけを5種へ拡張し、旧v1にはアトラスを後付けで認めません。旧keyの削除・更新・初期化はありません。旧版タブが新種入りデータを読んだ場合は、従来の未知データ保護が優先されます。

## 行動と表示はゲーム上の近似
- 頭角1本＋胸角2本、6脚、左右の上翅と収納後翅。胴と頭約20cm・角込み約38cmは従来模型と並べるための**表示寸法**で、実物の大きさではありません。
- 明るい林の低い枝は観察用の配置。通常の短い歩行から、前/側方の急な接近や近くへの網の空振りに角を構え、支持のある枝上を最大0.70m後退します。静歩行や回り込みには再挑戦の余地を残します。
- 警戒距離/待ち時間/後退速度はゲーム調整値で、人に対する野生の反応を測定したものではありません。飛行・枝間移動・摂食・新しい餌道具は今回追加していません。
- 三本角だから必勝にはしません。自動相撲の既存計算で、押した後の踏ん張りに小さい役割差を追加するだけです。個体の表示寸法は勝敗へ使いません。

## 生態資料と模型の留保
[Houston Museum of Natural Science の公式提供解説](https://artsandculture.google.com/asset/atlas-beetle-chalcosoma-atlas/8AH6b-WzMawiSA) は、東南アジアの熱帯雨林・成虫の果実/樹液利用を紹介しています。[HHMI / Janelia](https://www.beautifulbiology.org/media-detail/weight-world-its-horns) は雄の頭角1本・胸角2本と角を使った争いを解説。[North Carolina Arboretum](https://ncarboretum.org/2016/10/12/bugs-life-arboretum-entomology-101/) は主な夜行性と夕方の活動を紹介しています。

図鑑は今回確認できた種/地域/成虫の範囲に限定し、亜種・発生月・実測筋力を断定しません。資料写真の転載/テクスチャ化/輪郭トレースはしていません。模型の細かな種特有の曲率や色は写真実見未照合の暫定表現です。

## 検査と試遊
`node --test tests/*.test.mjs`。Atlasの個別検査は `node --test tests/atlas-*.test.mjs`。

実Three.jsメッシュの角接続・6脚/枝接地・観察と土俵の収まり、純粋動作の警戒/後退/捕獲凍結、実mainの網→図鑑→保持→COM→散策復帰→任意返却、旧保存/失敗/二重操作を対象とします。DOM/storage/WebAudio/rendererは代用品を含み、実WebGL・実音・本物の保存・性能・自然さ/楽しさは未確認です。

試遊は入口の右の枝で三本角を見つけられるか、急接近と静歩行で動きの違いが分かるか、捕獲後にその虫を仲間にして相撲へ入り、返すまで迷わないかに絞ってください。
