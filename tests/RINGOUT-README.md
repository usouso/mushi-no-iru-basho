# 場外だけで決着する見守り相撲

`node --test tests/ringout-*.test.mjs tests/beetle-battle.test.mjs`
全体は `node --test tests/*.test.mjs`。Node24.22.1、追加依存なし。

- 位置が±4に達した場合だけring-outの勝者。12交換の位置優勢判定を撤去し、最大36交換/59.6秒で未決着なら位置に関係なくtime-limitの引分。入力・模型サイズ・描画frame数で勝者を変えません。最初12交換の圧力/動作/エネルギーは従来通りです。
- 論理勝敗だけで画面へ勝者を出さず、実際の敗者の胴内側と支持脚が白い線の外へ出てから「場外！」、最終1.95秒の動作が着地してから勝者。通常動作は1.42秒。台の外周に安全な余白を設け、勝負の白線は縮めません。
- 25組/双方の場外、サイズを含む50終端clip、中央の偽勝者拒否、dt0/中断/再開/reduced-motion、時間切れ引分、捕獲保有から実mainへの一巡を検査します。DOM/WebGL/WebAudio/保存は代用品を含みます。
- 12,800固定seed試合の試料では場外67.8%、時間切れ引分32.2%。特に踏ん張る同種は引分が多いので、後の体感調整余地として残します。必ず勝者を付ける隠れ補正や怪我/永久損失はありません。

実GPUで線外の動きが明確か、文字が読みやすいか、待ち時間が楽しいかは未確認。CPU接触・投影や静的CSS検査は実画面合格ではありません。
