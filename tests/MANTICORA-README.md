# マンティコラ — Manticora latipennis 雄（0.37.0導入時）

以下は固定個体として導入した時の仕様です。0.38.0の明示次散策での個体差と保存互換は [MANTICORA-INDIVIDUALS-README.md](MANTICORA-INDIVIDUALS-README.md) を参照してください。旧散策の固定個体は引き続きこの範囲です。

既存 `savanna` の露出した土に、固定・未計測の `insect-2` を追加。旧 `dungbeetle/insect-1` と玉の道は保持します。大頭・左右非対称の曲がった顎・黒い地上の輪郭を探します。

## 遊ぶ範囲
- 地上の短い歩行→接近/空振りへの顎の警戒→走行。静かな接近から捕獲でき、観察・図鑑・仲間・見守る相撲・返却へ接続。
- 方向転換は足を交互に置き直します。180度で約3.7秒かかるゲーム動作で、素早い自然な逃走を実画面で確認したとはしていません。
- 29種・6区画、仲間/相撲12種。新個体の体長と表示指数は未計測。自然寸法をゲーム表示寸法へ置き換えません。
- 相撲の新種組は実顎と相手硬部の短い押し合い→解放→歩いて場外へ。テナガコガネ相手は既存の前脚接触。持上げ/投げ/自然の闘争再現ではなく、非殺傷のゲーム表現です。
- 旧11種の戦闘ルール・旧模型は維持。大きさによる新しい強さ補正はありません。
- 保存キー/形式、g1/g2/g3散策7枠、旧固定個体、500文字メモ/120文字場所は維持。29種に応じた読書込の有限上限は116830文字。旧保存を削除しません。

## 再実行できる限定検査

Node 24 の既存環境で、リポジトリ直下から実行します。追加依存は不要です。

```sh
node --test tests/manticora-model.test.mjs tests/manticora-study.test.mjs tests/manticora-support.test.mjs tests/manticora-data.test.mjs tests/manticora-main-loop.test.mjs tests/manticora-battle.test.mjs tests/published-graph.test.mjs
```

新模型/実足、地面と旧玉経路、停止/転回/捕獲復帰、保存6条件、実main経路4条件、相撲4群と配信graphを検査します。相撲は23順序組×両終局46clipの実60Hz、実接点/支持/骨長/左右顎/終端/画角を有限サンプルで確認。旧11種は具体的な新分岐除去後のsource hashと22終局を照合し、全旧組を再実行したとはしません。

mainはproductionコードをDOM/renderer/MapStorageの代用で動かします。実ユーザーデータを使った保存試験や初期化は不要です。これらは**実WebGL・実音・実ブラウザ保存・人間試遊の合格ではありません**。

新種戦闘の実面配置は生成時に最大7候補だけ調べ、毎frame再計算しません。この検査環境では平均185ms/最大341msでしたが、実機の開始待ち時間は未確認です。小さい端末の見やすさ、脚運びの自然さ、接近/逃走の緊張感、押し合いの面白さは今後の試遊対象です。

## 生態の根拠と展示上の限界

[華西昆虫博物館の Manticora latipennis 標本ページ](https://artsandculture.google.com/asset/manticora-latipennis/jQFB1FqtCbDTlQ) はザンビア Kafue National Park の採集地と雄の大頭・左右非対称の曲がった顎を説明しています。**正確な微生息地は未確認**です。今回の乾いた草地区画は観察しやすいゲーム上の展示配置で、採集地点の植生や自然な同所分布の再現とは主張しません。

[Carnegie Museum の Manticora 解説](https://carnegiemnh.org/manticore/) は属一般の資料です。その活動時刻を本種の確定的な説明へ置き換えません。速度・警戒・押し合いはゲーム調整値です。別種 M. scabra の林地採集記録を本種へ流用しません。

模型は自作。写真転載・輪郭トレース・新音源なし。属の捕食性を理由に餌や殺傷を追加していません。
