# アトラスの警戒・後退 — 限定修正

## 変更すること
- 普通の接近と同じように、空振りにも虫の向きを考慮します。背後からの空振りだけで、プレイヤーのほうへ逆に後退する矛盾を直します。候補選別時に判断し、背後のアトラスが別の正当な反応対象を遮らないようにします。
- 正面の警告を0.35秒から0.18秒、枝上の後退速度を0.18m/sから0.36m/sへ。一つの候補として比較したゲーム調整で、実際のアトラスの計測値ではありません。
- 加速・減速の時間、最大70cmの経路、支持枝、模型、網の2.6m射程、静かな接近、相撲・保存・音は変えません。

速く寄れば必ず捕れなくなる変更ではありません。最初の正確な網は残り、退避中でも見えて届く虫は捕れます。捕獲不可の隠れたフラグや瞬間移動は追加しません。回り込む・静かに近づく余地を維持します。

## 確認
```sh
node --test tests/atlas-response-*.test.mjs
node --test tests/atlas-study.test.mjs
node --test tests/published-graph.test.mjs
```
既存Node.jsだけで実行できます。CPUの実模型・実支持・シミュレーション・入力/保存の代用を用います。**実画面、実音、実ブラウザ保存、速い脚の自然さ、捕まえる緊張感は未確認**です。

## 試すなら
東南アジア林の入口右の太枝で、三本角のアトラスを探します。正面で空振りした後の後退、静かに横へ回った時の捕獲、返却後の動きが分かるかを確認できます。前より難しいだけ、足が滑る、予兆が短すぎると感じた場合も改善点です。元セーブを削除する試験は不要です。
