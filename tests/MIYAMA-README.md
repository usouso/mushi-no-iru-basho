# ミヤマクワガタ — 既存林縁の樹皮面

**Lucanus maculifemoratus の比較的大きな雄1表現**を、既存の温帯林縁へ追加します。左右へ張り出した頭の後ろと大顎を見比べる虫です。ノコギリクワガタの色替えではなく、頭・大顎・体の座標を自作しています。新しい区画・餌・音源・相撲ルールは追加しません。

## 探す・捕る・連れていく
- 温帯の林縁の太い生木、その南東側の低い樹皮面を見ます。同じ木の別面にいるゴマダラカミキリとは、頭の張出し・大顎・触角を見分けます。
- 6脚が実際の樹皮面に沿い、短く登り下りします。警戒で大顎を構え、最大8cm上へ移ります。固定の面で行うゲーム近似で、野生の逃避距離・反応速度の再現ではありません。上端でも見えて届けば捕れます。
- 捕獲→観察/自動図鑑→任意メモ→返却または仲間→見守り相撲→散策へ。保有中は元の個体を野外から除き、同じ虫を複製しません。敗北・取消で仲間を失いません。
- 胴頭約19cm・大顎を含む前後約30cmは表示補正です。今回は固定の未計測個体で、自然の体長・大きさ記録を捏造しません。サイズによる相撲加点はありません。

## 検査
```sh
node --test tests/miyama-*.test.mjs
node --test tests/published-graph.test.mjs
```
追加依存不要、既存Node.jsを使用。実Three.js模型・既存木の三角形・接点・カメラをCPUで扱い、DOM/音/保存は代用します。**実WebGL・実音・実ブラウザ保存・発見しやすさ・自然な動きは未確認**です。元セーブの削除や故意の破損試験は不要です。

## あとで見る点
1. 木の表面を少し回って、カミキリとの輪郭差や頭の張出しに気づくか。
2. 捕獲・観察・返却の姿勢に、脚や大顎が浮く/食い込む違和感がないか。
3. 仲間にして見守る押し合いの接触と場外が分かり、次の虫を探したくなるか。
