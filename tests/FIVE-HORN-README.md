# ゴホンヅノカブト — 既存林区画の1種追加

**Eupatorus gracilicornis の成虫雄1表現**。立ち上がる頭角1本と、前胸へ独立してつながる2対の角を見比べます。既存の東南アジア林に、生木につながる斜めの太枝と固定1個体を追加します。新区画・新しい餌・音源・相撲ルールは増やしません。

## 一巡
- 東南アジア林の入口右にある生木の低い斜め枝で、黄褐色の背と5本の黒い角を探します。既存のアトラスの3本角とは別の虫です。
- 枝に沿って少し登り下りし、速い接近や空振りで警戒・退避します。横から静かに近づいて網を向けられます。30°の低い枝、速度、反応距離は遊びの調整で、野生の典型的な姿勢・行動計測ではありません。
- 捕獲で図鑑と場所を自動記録。回して観察、任意メモ、返却、仲間として保有、見守り相撲へ進めます。保有中は元個体を野外から除きます。同種の入替は明示確認、敗北・引き分け・取消で失いません。
- 固定の未計測個体です。胴頭約22cm／体軸方向の角込み約35cmは見やすさのためのゲーム表示寸法であり、実物のmm測定や最大記録ではありません。大きさによる相撲加点はありません。

## 再実行
既存Node.jsを使い、追加パッケージ不要です。

```sh
node --test tests/five-horn-*.test.mjs
node --test tests/published-graph.test.mjs
```

実Three.js模型・支持面・接触点をCPUで検査します。保存・DOM・音・描画は代用です。**実WebGL・実音・実ブラウザ保存・実際の見つけやすさや自然さは未確認**です。旧版は未知の新種がある保存を読取り専用に保ち、元キーや記録を削除しません。

## あとで確認すること
1. 枝の傾きと立ち上がる角を手掛かりに見つけ、静かに横へ回って捕れるか。
2. 5本の角が区別でき、首・脚・枝への明白な食い込みがないか。
3. 仲間にして相撲を見た後、元の散策へ戻り別の虫を探したくなるか。

実セーブの削除・故意の破損や容量不足テストは不要です。
