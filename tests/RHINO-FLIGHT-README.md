# カブトムシの短飛行 — 検査と試遊

夜の既存のカブトムシ1種だけを対象に、警戒後の短い飛行と同じ太枝への着地を追加します。新種、音、捕獲距離、個体ID、大きさ、保存形式、虫相撲のルールは変更しません。

## 挙動
- 普通・速い接近や近くの空振りに気づくと、頭角を構え、上翅を開いて離陸します。
- 静かに近づく、先に正確に網を出す、飛行後に戻る枝で待つ、という捕まえ方は残ります。
- 空中でも同じ距離・向き・遮蔽の判定で捕獲できます。不可視化や瞬間移動はしません。
- 捕獲中は飛行姿勢と時計を止め、放した場所から続けます。仲間として保有した個体は野外に二重出現しません。
- 飛行に対応するのは安全な空間を点検した既存の木だけです。別の支持面を勝手に飛行対応へ変えません。

## 再実行
既存の Node.js で、追加のパッケージ取得をせず実行できます。

```sh
node --test tests/rhino-flight-*.test.mjs
```

試験は実 Three.js の模型・配置とシミュレーションを使いますが、ブラウザの描画や音声を置き換えた検査も含みます。自動検査の合格は実画面の自然さ、聴感、操作の楽しさの確認ではありません。

## 試遊の確認点
1. 急いで近づいたとき、警戒から飛び立つ流れが見えるか。
2. 静かに寄る・待つ・空中を狙うと、納得できる捕まえ方ができるか。
3. 開く翅、離れる脚、戻って枝に着く動きに目立つ貫通や瞬間移動がないか。

## 生態資料とゲーム近似
- [McCulloughほか2012、著者の大学研究室公開論文](https://wordpress.clarku.edu/mcculloughlab/wp-content/uploads/sites/739/2023/09/McCullough-et-al-2012.pdf)：雄の自発的な離陸と飛行を扱います。現在の人への反応距離や同じ枝への帰還を実証する資料ではありません。
- [Truongほか2014、非跳躍離陸の研究](https://doi.org/10.1016/S1672-6529(14)60020-2)：種の非跳躍離陸を参考にしています。本文の詳細条件は未確認です。
- [Truongほか2012、大学研究室公開論文](https://www.umt.edu/emlen-lab/documents/lab-publications/truong2012.pdf)：上翅・後翅の開閉を参考にしています。飛行解析は雌を対象とするため、その数値を雄へ転記していません。

模型は自作です。後翅の折り畳みは剛体パネルによる簡略表現で、翅脈・細かい折り線の忠実な再現ではありません。警戒距離、時間、飛行経路、速度、同じ枝へ戻る動きはゲーム上の調整です。写真や論文図版を配信素材として使用していません。
