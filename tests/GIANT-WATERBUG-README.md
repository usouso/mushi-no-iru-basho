# 0.45.0 タガメの浅い池での一巡

既存草地の池に Kirkaldyia deyrolli 成虫1表現を追加。固定の未計測個体で、性別を断定する細部は再現していません。32種／8区画／相撲14種。今回は水生種を陸上相撲へ追加せず、捕獲・観察・図鑑・メモ・放虫へ接続します。古い31種・14相棒・gen5の8個体と最大記録を保持します。

## 再実行
Node24系、rootから。追加依存不要。

```sh
node --test tests/giant-waterbug-*.test.mjs tests/published-graph.test.mjs
```

新しい6ファイル30条件＋配信graph1条件。全旧suiteの再実行ではありません。

## 形と動き
頭胴約24cmの自作表示模型です。自然の体長紹介45〜70mmとは別です。灰褐色の平たい体、太い前脚と先端爪、中後脚、平たい後脚の縁、重なった前翅、腹側の口、短い触角、腹端の左右の呼吸管を表します。内部後翅、正確な触角節数、性差、飛行・捕食・繁殖は未モデル化です。10mesh／2,320triangles／texture0。

四本の中後脚が、実際の細い茎に接します。前脚は自由に開き、支持していると偽りません。尾の両先端は実水面に一致。予兆→前脚を閉じる→茎を離す→短く潜る→泳ぐ→向きを変える→戻る→茎をつかむ、という連続した動きです。警告.7秒／離す.55秒や休止9〜15秒は独自のゲーム調整で、自然測定値ではありません。

## 具体的な有限証拠
- 1本の茎は16角柱64trianglesで、既存池の実groundへ根を置く。元の地形・水material・アメンボ／ゲンゴロウ支持を変えない。
- 四本のnative足先→茎の最大ray差約0.24nm。実study87pose／496,944vertexの最小底余裕約12.8cm。連続衝突全体の証明ではありません。
- 急接近では最初の網が届く前に予兆を確認、静歩では休止のまま捕獲可能。予兆中も届く網は有効で、必ず逃げる・捕獲不能にする変更ではありません。
- 実mainの岸からの網入力とLOS、観察、メモ、放虫再捕獲、旅行とreload、失敗writeの旧raw保持を確認。観察3画面比×16方位×3傾きの822,528vertexは枠内、最大NDC絶対値約.602。DOM/WebGL/audio/Mapの代替を使う検査であり、実ブラウザ合格ではありません。
- 最大許容journal文字列128,962文字。旧31行のメモ500／場所120と新規行を保存・fresh読取。古い044が新種を読めない場合、fresh/staleとも自動で新rawを壊さないことを確認。現行journalはpost-write readbackを行わず、書込み後throwは未保存扱いでCASが盲目的再試行を防ぐ従来仕様です。

## 回帰テストの配信形式修正
044のdragonfly sourceguardはローカルgit履歴に依存し、版token更新にも弱かったため、ゲーム本体とは別のテスト不備として訂正します。既知の追加部分だけを厳密に逆変換し、元の固定hashへ一致することを確認した旧sourceを使います。公開ZIPにないgit履歴を要求しません。現在のimport queryは検査する基準版のqueryへ正規化し、最終token付与後にも該当guardを確認します。旧043/044凍結束を黙って差し替えてはいません。
