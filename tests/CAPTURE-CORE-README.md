# 初回の白チョウと枝上甲虫の反応

`node --test tests/capture-core.test.mjs tests/capture-awareness.test.mjs tests/branch-*.test.mjs`
全体は `node --test tests/*.test.mjs`（Node24.22.1、外部依存なし）。検査ファイルは本番から読み込みません。

## 限定差分
- 白チョウを既存の警告→連続飛行へ追加。歩行3.2m/ダッシュ4.2m/静歩行.95mはゲーム調整。初回でも網2.6mの外で警告し、停止で減衰、静歩行には捕獲余地を残します。野外で止まる翅だけを小さく動かし、観察/捕獲中/既存の飛行/足場を変えません。
- カブト/ノコギリは、世界の支持物が明示したrootの軸方向限界を持つ場合だけ新しい反応を使います。通常歩行の途中は次の半歩へ制動→頭/顎の予兆→脅威と反対へ短く退避。端では停止でき、脅威がなくなれば連続して戻ります。幹・別の高さの枝へ移りません。
- 出現位置・個体サイズでhomeが動いても、支持限界のworld座標は固定。既存の図鑑/仲間/散策キー・IDは変更せず、虫の大きさ・網射程・相撲計算・音素材も変更しません。新しい枝や種はありません。
- 未指定の旧study経路と、それを使うメタリフェルは保持。甲虫に共通の飛行や無敵時間を追加しません。

## 対象検査
白チョウ初回dash/quiet/停止、120Hz/60Hz/粗いdt、最近1匹への実空振り、遮蔽/保持除外、連続離陸・着地再捕獲・放虫、dt0凍結。旧トンボ/セミの6半径値は固定。
甲虫は前後/横の脅威、端での停止、刺激を毎frame受けても動作を初期化しないこと、解除後の戻り、警告/退避/端での捕獲/放虫、3サイト×サイズの実脚ray支持、inspection/戦闘との模型隔離を対象にします。

## 生態と表示の区別
[UC Davisのモンシロチョウ調査](https://butterfly.ucdavis.edu/butterfly/pieris/rapae)は花利用、[山口大学のカブトムシ野外研究](https://www.yamaguchi-u.ac.jp/wp-content/uploads/2022/11/22110804.pdf)は樹液場での他種との相互作用、[森林総研のノコギリクワガタ記録](https://www.ffpri.go.jp/kys/business/tatuta/konchu/nokogirikuwagata.html)は樹液や灯火への飛来を参考にしています。これらは今回の人に対する距離・速度・警告姿勢の測定根拠ではありません。後退は限定したゲーム近似で、これらの甲虫が自然に飛ばないという意味ではありません。写真や他ゲーム素材は流用していません。

実WebGL・聴感・実保存・警告の見つけやすさ・緊張感は未確認。CPU数値や模擬mainを人間試遊の合格と置き換えません。
