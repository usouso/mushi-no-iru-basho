# ゴライアスと森林縁 — 検査と試遊

雄の **Goliathus goliatus** を1表現、カメルーンの森林を参考にした小さな区画へ追加します。新しい餌・時間帯・相性・音源は追加しません。元の5区画、24種、個体差対応5種、保存キーは維持します。

## 遊びの一巡
- 表紙または休止メニューから「中部アフリカ森林縁の再現区画」へ。明るい道沿いの太い木2本の低い枝で、白黒の胸・褐色の上翅・短いY字角を探します。
- 固定2個体が短く歩き、速い接近や空振りに警戒して枝上を後退します。静かに寄れば捕獲する余地が残ります。飛翔・摂食は未実装で、樹液跡は見た目の手掛かりです。
- 捕獲で図鑑と場所を自動記録。任意メモ、観察、放虫、仲間として保有、既存の見守り相撲へ進めます。同じ種は1匹まで、入替と返却は明示確認です。
- 保有中の元個体は野外から除かれ、別個体まで消えません。返すと元の支持位置で動きを再開します。敗北・取消・引き分けで仲間を失いません。
- 新種は未計測の固定表示です。胴から頭まで約22cm、角先まで約25.5cmはゲームの表示寸法であり、実物の測定値ではありません。大きさによる相撲の加点はありません。

## 新種の相撲表現
短いY字角は、既存の長い角と同じように相手の腹下へ深く入れず、角と相手の胴の前面を合わせて押します。模型を伸ばさず実際の表面を接触に使います。既存の場外勝ち／約1分での明示的引き分け、見守り方式は変えません。生物同士の実際の勝敗を予測するものではありません。

## 再実行
既存の Node.js を使い、追加パッケージ不要です。

```sh
node --test tests/goliath-*.test.mjs
node --test tests/published-graph.test.mjs
```

保存はMapと排他ロックの代用、mainはDOM・音・描画の代用を使います。Three.jsの実模型・足の支持ray・角接触・場外・カメラ範囲をCPUで確認します。**実WebGL、実音、実ブラウザ保存、見やすさ・自然さ・楽しさは未確認**です。旧版の別タブは未知の新種を含む保存を読取り専用として保ち、勝手に削除・上書きしません。

## 最小の試遊
1. 太い木と樹液跡から、白黒の胸や短い角を見つけられるか。
2. 捕獲→観察→仲間→相撲→元の散策へ戻り、もう1匹との違いや次の虫へ興味が湧くか。
3. 短い角の押し合い・脚の接地・場外の決着に、明白な食い込みや浮きがないか。

- [De Palmaほか、2020年の分類再検討](https://www.researchgate.net/publication/339274442_Barcoding_analysis_and_taxonomic_revision_of_Goliathus_Lamarck_1802_Scarabaeidae_Cetoniinae)：狭義の本種と南部アフリカの近縁型を混ぜず、カメルーン森林を参考にします。
- [Luiselliほか、2025年の保全研究](https://www.researchgate.net/publication/388498332_Red_Listing_African_Goliath_Beetles_Assessing_Threats_and_Conservation_Needs)：成熟した森林・林縁と樹液を背景にします。ゲームの低い枝、反応距離、退避速度、同じ場所で待つ行動は生態の計測値ではありません。
