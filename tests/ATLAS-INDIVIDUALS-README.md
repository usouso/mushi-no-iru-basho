# アトラスにも、散策ごとの個体と大きさ

新しい散策ではアトラスが7番目の個体枠に加わります。既存の散策を読み込んだだけでは、進行中の5/6個体や昔の固定アトラスを作り直しません。

- 大きさ100〜115は同種の**表示指数**で、自然のmm計測ではありません。大きいだけで相撲が強くなる変更はありません。
- 同じ個体の大きさ・出会う位置・動作の種は保存され、区画移動、観察、再読込で引き直しません。「次の散策」の保存確認が成功して初めて新個体へ進みます。
- 過去の未計測の仲間を勝手に計測しません。新しい散策の野生個体とは別個体として扱い、仲間の入替えは明示操作のままです。
- 今回のアトラスは同じ枝の3地点。足場を拡大せず、最大個体でも後退を0.70m以内・通常移動を0.12m以内の接地歩幅へ内側丸めします。最大1.15倍では0.690m/0.115m。世界の歩速は従来値を維持します。
- 大個体の押合いで膝が床へ押し潰される問題を、この組の脚だけ固定骨長で解きます。模型寸法や勝敗規則は変えません。
- 狭い観察画面の頭角は、旧固定個体にもあった縦画面の微小なはみ出しを修正。野外/相撲の大きさは変更しません。

## 保存互換
同じv2キーで生成世代3を追加。旧世代1/2の5/6枠、既存ID、乱数、最高記録、旧キーの元データを保持します。保存拒否・読戻し不明では表示中の旧世界を維持し、不確かな書込みを勝手に巻戻しません。

古い版のタブは新しい世代を扱えず、読取専用や旧固定世界の表示になることがあります。データを消さず、新しい版へ読み直してください。実旧クライアントの代用ストレージで、未知世代を上書きしないことを確認しています。

## 再現検査
```sh
node --test tests/atlas-individual-*.test.mjs tests/expedition.test.mjs tests/giant-individual-data.test.mjs tests/published-graph.test.mjs
```
追加依存なし。テストは本番runtimeへ読込まれません。

実Three.js形状/接点/骨/足場と、実mainの捕獲→測定→仲間→COM取消→移動/再読込→返却/再捕獲を代用DOM/保存で検査しています。**実WebGL・実音・実ブラウザ保存・大物を捕る嬉しさは未検証**です。枝上面の足中心余白は最大個体で約0.56mmと小さく、描画上の自然さは実機で見る必要があります。

あとで見る点：新しい散策で大きさの違いに気づくか、自己最大を捕った記録が嬉しいか。旧セーブを削除して試す必要はありません。
