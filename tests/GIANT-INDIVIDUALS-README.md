# オオクワガタの個体差（0.26.0）

種数24・区画5・相撲対象7はそのまま。既存オオクワガタ雄にだけ、新しい散策ごとの3つの開始位置・歩行seed・大きさ指数を追加します。新区画/模型/音/相撲ルールを追加しません。

## 試すなら

夜の樹液の木の左、低い樹皮際を探します。前の散策で遊んでいた人は「新しい散策を始める」を一度選ぶと、オオクワガタも抽選対象になります。リロード・観察・区画往来では抽選し直しません。捕獲するとサイズを一度記録し、同種の自己最大を更新した時に表示。新しい個体を探したいと思えるかを見てください。

大きさ100〜115は表示の同種比較です。基準模型の大顎込み約29cmが最大約33.35cmになる表示補正で、実寸計測・自然の分布/希少度・強さの倍率ではありません。大きくても相撲ルールに加点しません。小型雄の顎型・雌雄差の再現は今回対象外です。

## 保存と仲間

- 旧散策キーを削除/上書きせず、新しい保存キーへ現在5枠・計測・最大記録を保護コピー。現在の出会いを差し替えず、明示の次散策でだけ6枠へ進みます。初めて遊ぶ人は6枠から開始。
- 新保存があればそちらを優先し、古いタブの旧キー後書きを再取込しません。旧5枠のseed抽選/IDはそのまま、新しいオオクワガタだけ別の生成IDです。
- 失敗/競合/結果不明時は現在の散策を維持し、原データを消しません。ブラウザが保存やWeb Locksに対応しない時は未保存を示します。
- 旧固定仲間のサイズを捏造せず、未計測のまま保持。同じ場所の新個体は別個体として見つけられ、仲間は既存の確認付き入替操作だけで交代します。過去の仲間を返しても、現在の野生個体を複製したり移動したりしません。

## 再実行

Node24.22.1、追加install不要。ルートで:

```sh
node --test tests/giant-individual-*.test.mjs tests/expedition.test.mjs
node --test tests/published-graph.test.mjs
```

保存はMapとWeb Locks代用環境、mainもDOM/音声代用と実Three形状の検査です。実ブラウザ保存・音・WebGL・パッド・自然さ/見つけやすさ/喜びは未確認。

支持面を拡大して誤魔化さず、倍率ごとにroot高・歩幅・絶対経路を補正。最大倍率と3開始位置で実脚skin、庇/壁/枝端、支持脚の滑りを確認します。角/顎の接触と相撲の画角は実meshのCPU検査であり実動画ではありません。旧4種の表示/生成fixture、固定Atlas/ゾウカブトの未計測状態を維持します。

## 生態の参照と限界

[岐阜県の紹介](https://www.pref.gifu.lg.jp/page/4843.html)は雄30〜55mmを大顎込みで記載。[Kim & Kim (2010)の原著](https://www.zin.ru/animalia/coleoptera/pdf/kim_kim_2010_review_lucanidae_korea.pdf)は雄27.0〜76.1mm、大顎先端から上翅末端の資料範囲です。地域や標本の異なる値を混ぜてゲームの自然分布とはせず、個体の自然mmへ換算しません。原種の形・暮らしは `tests/GIANT-STAG-README.md` の参照を引き継ぎます。
