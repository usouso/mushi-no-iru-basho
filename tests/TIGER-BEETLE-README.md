# ハンミョウの土道・短い飛行の検査

この変更は固定個体1匹を温帯の既存土道へ追加します。旧34種の寸法・活動、10区画、相撲15種、保存世代7／10個体／9種の測定対象は変えません。新しい音・外部依存・通信・画像素材はありません。

## 実行

既存の Node 24 で、リポジトリ直下から実行できます。テストは本番から読み込まれません。

```sh
node --test tests/tiger-beetle-*.test.mjs
node --test tests/journal-capacity.test.mjs tests/journal-migration.test.mjs tests/giraffe-individual-field.test.mjs tests/giraffe-individual-main.test.mjs tests/published-graph.test.mjs
```

古い版の固定件数・世代をそのまま検査する他のテストも保存しています。今回、全ファイルを一括実行したとはしていません。新しい逆変換は限定した追加を取り除き、旧版の固定SHAと照合します。古い期待値を緩める処理ではありません。

## 検査の境界

- 胴頭約18cmは読みやすさのためのゲーム模型。実際の測定値や最大記録にはしません。6脚の付け根を胸に置き、大きい眼・細い前胸・長い脚・左右2上翅と2膜翅を自作しました。
- 殻を開く→膜翅を広げる→離地→短い弧→足を戻して着地→膜翅収納→殻を閉じる。膜翅は消したり縮めたりせず、一定面積の簡易関節です。自然の精密な折り目・飛翔力学の再現ではありません。
- 3停止点は既存地形の実三角形。追加の地面板や草木の配置変更なし。静歩・通常・急接近と空振り、全段階の捕獲・放虫、地上での向きの飛び、実模型と地形の接触を限定検査します。飛行距離・待ち時間・反応はゲーム調整です。
- 捕獲状態・個体の経路進行・図鑑メモ・既存の仲間／個体差データを分離。未知の新しい記録を旧版で開いても上書きしない検査を含みます。保存を削除する必要はありません。
- 実ソースを評価するDOM/MapStorage/Audioのテスト用代替、ネイティブThree三角形のCPU検査です。実WebGLの見え方、実音、ブラウザの保存耐久性、ゲームパッド、操作感・楽しさは未検証です。CPU画像をゲームのスクリーンショットとは扱いません。

雌雄・自然の大きさ分布・正確な羽ばたき回数・反応距離は今回の資料から断定しません。既存の飛ばないManticoraを色替えして追加したものではなく、短い飛行を追う別の探索表現です。
